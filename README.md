# Модель лесного пожара (клеточный автомат)

Лабораторная работа по курсу компьютерного моделирования №1.
Модель распространения лесного пожара методом клеточных автоматов.

## Автор
Вадим Козырев

## Описание

Клеточный автомат на двумерной решётке. Каждая клетка — участок леса:
- пустая / сгоревшая
- горит
- хвойное дерево
- лиственное дерево
- кустарник

Исследуется влияние **типа окрестности** (фон Нейман / Мур)
и **числа начальных очагов** (1, 3, 9) на динамику пожара.

## Установка

```bash
python -m venv .venv
source .venv/Scripts/activate   # Windows Git Bash
pip install -r requirements.txt
```

## Запуск

**Все сценарии (2 окрестности × 3 очага):**

```bash
python -m src.main run --width 100 --height 100 --steps 300 --output results
```

**Параметры CLI:**

| Флаг | По умолчанию | Описание |
|------|--------------|----------|
| `--width` | 100 | Ширина поля |
| `--height` | 100 | Высота поля |
| `--steps` | 200 | Число шагов |
| `--output` | `results` | Папка для результатов |
| `--seed` | 1097 | Seed генератора |

## Результаты

После запуска в папке `results/` появятся:
- `dynamics.png` — динамика числа горящих деревьев
- `comparison.png` — сравнение окрестностей
- `vegetation.png` — динамика по типам растительности
- `burn_rates.png` — % сгоревшей растительности
